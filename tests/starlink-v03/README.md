# Starlink 太阳观测器 v0.3 测试

一条信息不足的待办可以先保存和完成。补上交付物后，观测器应把它放进对应扇区，保留完成状态和首次科研评分。交互测试从录入开始，实际走完这条路径。

## 运行

应用回归测试需要一份本地 v0.3 离线 HTML，或包含 `model.js`、`import.js`、`controller.js` 和 `export.js` 的 `solar` 源码目录。测试读取指定版本的模块，使用内存中的虚构任务与存储。安装 Node.js 22 或以上版本、Python 3.8 或以上版本后，从仓库根目录运行以下命令。常规测试无需安装 npm 或 pip 包。

```sh
cd tests/starlink-v03
node run.cjs "/path/to/Starlink_Orbit_3D.html"
```

也可将最后一个参数换成本地 `solar` 目录。完整命令会依次运行 Node 应用测试和 Python 异常检测测试，任一测试失败时进程退出码为非零。可用环境变量 `PYTHON` 指定 Python 可执行文件。

只有 GitHub 仓库时，可以直接跑独立的 NAB 合成实验。

```sh
python3 -m unittest discover -s nab -p 'test_*.py'
```

## 测试覆盖

| 模块 | 检查的行为 |
| --- | --- |
| 分类与排轨 | 交付物优先、待确认无方位、工具扇区 225°、截止日与新加坡日期边界，以及全部 32 种紧迫度、目标影响和阻塞值组合 |
| 记录与科研评价 | 未知值与明确的零分、手选轨道、首次输入冻结、回填样本筛选、重复 ID 和跨日完成计数 |
| 操作流程 | 两步录入、未定位待办完成后补齐并点亮、重载与撤销、随观测日变化的轨道、真实与演示记录分开统计 |
| Excel 导入 | 现场生成新旧格式 XLSX，检查压缩、空值、重复记录、无效字段和完成后补录的数据 |
| CSV 导出 | 只导出真实行，区分空值和零，保留首次与当前轨道，正确处理换行、引号和可能被表格解释成公式的标题 |
| 日级异常检测 | 以合成日序列检查滚动阈值、预热、未来数据隔离、尖峰命中、漏报、窗外误报和重复提醒 |

交互测试使用 DOM 事件适配器和场景状态。另有可选的原生画布测试，用实际 2D Canvas 检查投影后的星点能否点选。它需要 `@napi-rs/canvas` 和包含 `scene.js` 的 v0.3 构建。

```sh
npm install --no-save --package-lock=false @napi-rs/canvas@0.1.100
STARLINK_TARGET="/path/to/Starlink_Orbit_3D.html" node --test optional/scene.test.cjs
```

## v0.3 历史回放摘要

在此前用于排查错例的同一批 54 条历史标题上，按第一份参考标注比较，结果如下。表中「待确认」是模型主动留给人判断的数量，三列之和均为 54。

| 版本 | 与参考标签一致 | 与参考标签不同 | 待确认 |
| --- | ---: | ---: | ---: |
| v0.2 | 20 | 34 | 0 |
| v0.3 | 24 | 1 | 29 |

v0.3 在 54 条中给出了 25 条建议，其中 24 条与参考标签一致。两次参考标注一致的 34 条中，v0.3 自动分对 24 条，其余 10 条待确认。为和旧标签比较，新增的工具类在这次统计中映射回旧标注的「其他」。历史记录导入回放还核对了 84 条有效任务和 67 条累计完成。此处只公开汇总，仓库中的合成样例用于验证行为；独立新任务上的分类表现与优先级误差要用新的盲标样本评估。

NAB 合成实验及上游评分器许可见 [日级异常提醒测试](nab/README.md)。
